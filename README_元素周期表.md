# 元素周期表（118 种元素 · 多配色方案 · 元素详解 · PDF 导出）

Python + Tkinter 桌面元素周期表。118 种元素按 18 列 7 行标准排布，镧系 / 锕系单独成行；
**不同族别用不同颜色**区分，内置 **8 套可选配色方案**；点击任意元素即在右侧展开详解
（主要化合物、主要存在形式、生产用途、地壳丰度、发现过程等）；一键导出与界面同色的
**着色周期表 PDF**，可附元素详情页。

## 一、运行

```bash
# 1) 安装依赖（首次运行需要联网）
pip install -r requirements.txt

# 2) 打开界面
python periodictable.py

# 可选：命令行直接导出，不打开界面
python periodictable.py --export 元素周期表.pdf
python periodictable.py --export 周期表_按族.pdf --scheme group --paper "A3 横向"
python periodictable.py --export 含详情.pdf --scheme abundance --element Fe
python periodictable.py --export 全元素手册.pdf --details        # 附带全部 118 个元素详情页
python periodictable.py --list-schemes                            # 查看全部配色方案
```

Windows 下可直接双击 `启动元素周期表.bat`（自动检查 tkinter 并安装依赖）。

> 界面需要 tkinter，Python 官方发行版自带（安装时勾选 Tcl/Tk）。
> 纯命令行导出模式不需要 tkinter。

## 二、8 套配色方案

| 键名 | 名称 | 说明 |
| --- | --- | --- |
| `category` | 元素族别（分类） | **默认**。碱金属、碱土金属、过渡金属、主族金属、类金属、非金属、卤素、稀有气体、镧系、锕系各一色 |
| `group` | 按族（18 列） | 周期表每一纵列一种颜色，共 18 色 |
| `period` | 按周期（7 行） | 每一横行一种颜色 |
| `block` | 电子区块 s/p/d/f | 按价电子所在轨道区块着色 |
| `phase` | 常温状态 | 按常温常压下的固 / 液 / 气态着色 |
| `abundance` | 地壳丰度（对数） | 渐变色，含量越高颜色越深；人工元素为“无数据”灰 |
| `electroneg` | 电负性 | 鲍林标度渐变，吸电子能力越强颜色越深 |
| `year` | 发现年代 | 越晚被发现颜色越冷，人工合成元素最冷 |

切换方案后表格、图例、导出 PDF 会**同步刷新**；格子上的文字颜色按底色亮度自动取黑或白，
保证任何配色下都清晰可读。

## 三、界面操作

| 操作 | 说明 |
| --- | --- |
| 单击元素格 | 右侧详情面板显示该元素全部信息，格子加橙色高亮框 |
| ◀ 上一个 / 下一个 ▶ | 按原子序数前后切换元素 |
| 搜索框 | 输入中文名 / 符号 / 英文名 / 序数（如 `铁`、`Fe`、`iron`、`26`）后回车定位 |
| 配色方案下拉框 | 切换 8 套配色，表格与图例即时重绘 |
| 复制详情 | 把当前元素的详情文本复制到剪贴板 |
| 导出 PDF… | 打开导出对话框 |
| 鼠标悬停 | 格子微微提亮，底部状态栏显示该元素一句话摘要 |

### 详情面板包含的字段

1. **基本参数**：相对原子质量、电子排布、电负性（鲍林）、常温状态、族 / 周期 / 电子区块
2. **发现过程**：发现年代、发现者与提出者、较详细的发现经过（多数元素有 3–6 句完整叙述）
3. **丰度**：地壳丰度（ppm / %）、宇宙丰度（相对 Si = 10⁶ 的原子数）
4. **存在形式**：自然界主要矿物与赋存形态
5. **主要化合物**：常见氧化物、卤化物、酸碱盐等（化学式按上下标排版）
6. **生产用途**：工业、冶金、电子、医药、农业等实际用途

## 四、PDF 导出

导出对话框可指定：

- **配色方案**：8 套任选，与界面当前方案一致
- **纸张版式**：`A4 横向`（推荐）/ `A3 横向`（格子更大）/ `A4 纵向`
- **选项**：是否含配色图例、是否附当前元素详情页、是否附全部 118 个元素详情页
- **保存位置**：默认 `output/元素周期表_<方案名>.pdf`，导出后可一键打开

PDF 特性：

- 自动嵌入系统中文字体（微软雅黑 / 黑体 / 宋体 / 苹方 / Noto CJK），找不到时回退 Adobe STSong-Light
- **化学式上下标真排版**：Fe₂O₃、H₂SO₄、²³⁸U、Na⁺、Cl⁻ 等按缩小字号 + 基线偏移绘制，不出现方框
- 生僻字（如 104–118 号元素的扩展汉字）自动回退为「钅卢」「钅杜」等可读写法
- 页首标题含中英文与配色方案名、导出日期，页脚含图例与说明

已生成的示例（在 `output/` 下）：

| 文件 | 说明 |
| --- | --- |
| `元素周期表_元素族别分类.pdf` | 默认分类配色，A4 横向 |
| `元素周期表_按族18列.pdf` | 18 列每列一色 |
| `元素周期表_地壳丰度.pdf` | 丰度渐变配色 |

| `元素周期表_含元素详情示例.pdf` | 周期表 + 铁（Fe）详情页，共 2 页 |

另有截图预览 `output/预览_周期表_*.png`。

## 五、文件结构

```
periodictable.py   程序入口（命令行参数 + 启动界面；导出模式无需 tkinter）
elements_data.py   118 种元素全量数据（化合物 / 存在形式 / 用途 / 丰度 / 发现过程）
color_schemes.py   8 套配色方案 + 图例 + 底色亮度自适应文字色
periodic_gui.py    Tkinter 界面（周期表网格、搜索、详情面板、导出对话框）
pt_pdf.py          PDF 绘制（reportlab，中文字体嵌入、上下标排版、三种纸张）
```

## 六、依赖

- `reportlab` —— PDF 生成
- `tkinter` —— 界面（Python 官方发行版自带）
- 可选：`pillow`、`pypdfium2`（仅用于生成预览图，非运行必需）

## 七、数据说明

- 元素数据为手工整理的科普级资料，相对原子质量取常用四位有效值，地壳丰度取常见参考值
- 104–118 号超重元素多为人工合成，丰度标注为「人工合成」/ 无数据
- 发现过程按主流科学史叙述编写，包含关键人物、年代与实验背景
