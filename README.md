# 万年历（公历 / 农历双显 + 节气 + 传统节日 + PDF 年历）

Python + Tkinter 桌面万年历。月视图、年视图都能整体看日历，每格上行公历、下行农历，
遇到二十四节气显示节气名，春节 / 元宵 / 端午 / 中秋 / 七夕 / 重阳等传统节日高亮显示，
并可按选中年份导出与界面同一套规则的 PDF 年历。

## 一、运行

```bash
# 1) 安装依赖（首次运行需要联网）
pip install -r requirements.txt

# 2) 打开界面
python wannianli.py

# 可选参数
python wannianli.py --year 2030          # 启动后直接定位到 2030 年
python wannianli.py --export 2026        # 不打开界面，直接导出 2026 年年历 PDF
python wannianli.py --export 2026 -o d:\2026.pdf --paper A4
```

Windows 下可直接双击 `启动万年历.bat`（会自动检查并安装依赖）。

> 界面需要 tkinter，Python 官方发行版自带（安装时勾选 Tcl/Tk）。
> 无界面导出模式不需要 tkinter。

## 二、界面操作

| 操作 | 说明 |
| --- | --- |
| ◀ / ▶ 或 ← / → | 月视图按“月”翻页，年视图按“年”翻页（↑ / ↓ 同效） |
| 年 / 月 输入框 | 直接跳到指定年份、月份（1900–2100） |
| 今天 | 回到当天所在月份（快捷键 Home） |
| 月视图 / 年视图 | 月视图 6 行大格子；年视图 12 个月一览 |
| 月份标题 | 中文月份后附英文全称，例如「1 月 January」 |
| 显示公历节日 | 是否显示元旦 / 劳动节 / 国庆等公历节日（蓝色） |
| 节日优先于节气 | 勾选：传统节日优先；取消：二十四节气优先 |
| 单击日期 | 底部状态栏显示该日完整信息（农历、干支、节日、节气）；年视图中单击会跳进对应月份 |
| 单击年视图里的「N 月」标题 | 直接进入该月月视图 |
| 导出 PDF 年历 | 弹出对话框选择年份、纸张（A4 / A3）与保存位置 |

快捷键：`←` `→` 翻页、`Home` 回到今天、`F5` 刷新。

## 三、显示规则（界面与 PDF 完全一致）

每一格两行：第一行公历日号，第二行按下述优先级取一个名称显示。

1. **重要传统节日**（红色）：春节、除夕、元宵节、端午节、七夕节、中秋节、重阳节
2. **二十四节气**（绿色）：立春、雨水……冬至（清明既是节气也是节日，按红色显示）
3. **其它传统节日**（红色）：中元节、腊八节、龙头节等
4. **公历节日**（蓝色，可关闭）：元旦、劳动节、国庆等
5. 其余日期显示**农历日名**（灰色）；农历初一显示农历月名（棕黄色），如「正月」「九月」「闰六月」

- 周末与周六周日的公历数字用红色显示，非当月的补位格淡化。
- 今天自动高亮（蓝色底 + 蓝框），选中的日期用橙色框标出。
- 规则说明：若某天既是普通传统节日又是节气（例如 2026-03-20 龙抬头 / 春分），默认按上面的优先级显示节气；取消「节日优先于节气」则反过来。

## 四、PDF 年历

`导出 PDF 年历` 对话框可指定：

- **导出年份**：任意 1900–2100 年
- **纸张版式**：`A4 横向`（12 个月排在一张 A4 纸上）或 `A3 横向`（同为一页，版面更宽裕）
- **选项**：是否显示公历节日、传统节日是否优先于节气（与界面开关独立，导出时按对话框设置）
- 页首含农历年份、生肖与全年传统节日一览，页脚含图例和页码

已生成的示例：`output/万年历_2026年.pdf`（A4）、`output/万年历_2026年_A3.pdf`（A3），
另有截图预览 `output/预览_*.png`。

## 五、文件结构

```
wannianli.py       程序入口（命令行参数 + 启动界面；导出模式无需 tkinter）
calendar_gui.py    Tkinter 界面（月视图 / 年视图 / 导出对话框，尺寸随系统 DPI 自适应）
lunar_service.py   农历核心：日期 → 公历/农历/节气/节日，统一“第二行显示什么”的规则
pdf_exporter.py    PDF 年历绘制（reportlab，自动嵌入系统中文字体）
theme.py           配色常量（浅色主题）
requirements.txt   依赖
```

## 六、依赖

- `lunar-python` —— 农历、二十四节气、传统节日计算
- `reportlab` —— PDF 生成（自动查找微软雅黑 / 黑体 / 苹方 / Noto CJK 等中文字体并嵌入，
  找不到时回退 Adobe STSong-Light）
